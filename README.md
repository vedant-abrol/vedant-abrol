# 💫 About Me

I'm a **Software Engineer, Full Stack Developer, and AI Engineer** with experience building **AI-powered products, production web applications, backend APIs, digital commerce workflows, payment systems, and cloud-based fulfillment pipelines**.

I enjoy working across the full stack, from polished user-facing interfaces to backend services, databases, cloud integrations, and GenAI systems. My current stack includes **React, Next.js, TypeScript, JavaScript, Node.js, Express.js, MongoDB, Mongoose, Python, Java, Scala, Spring Boot, FastAPI, AWS, GCP, LangChain, AWS Bedrock, OpenAI API, and ChromaDB**.

Most recently, I have been building the **eBook commerce and digital fulfillment platform at Paysfer eMart**, where I worked on product flows, checkout, Stripe payments, post-purchase eBook download experiences, Google Cloud Storage fulfillment, and EditionGuard DRM integration. This involved owning features end to end across frontend, backend, third-party APIs, payment webhooks, database workflows, and user experience details like loading states, payment states, error handling, validated download CTAs, and reader-specific guidance.

Before Paysfer, I worked at **IEEE**, where I built AI-powered internal platforms including a unified search experience, RAG pipelines, mentor/mentee recommendation systems, and GenAI summarization workflows using **Python, LangChain, DynamoDB, AWS Bedrock AgentCore, Spring Boot, Angular, AWS S3, Lambda, and OpenAI GPT-4**.

Earlier, I worked at **Scienaptic AI**, building and optimizing backend REST APIs for an AI-driven credit decisioning platform using **Scala, Play Framework, SQL, and Redis**, with a focus on API performance, backend reliability, and ML-powered underwriting workflows.

I like building systems that are not only technically strong, but also useful and reliable in the real world: clean interfaces, fast APIs, secure data flows, observable AI behavior, smooth checkout experiences, and products that feel simple even when the underlying workflow is complex.
