I work across the full stack — Python, Java, Scala, TypeScript — with deep focus on **LangChain, LangGraph, AWS Bedrock, FastAPI**, and the engineering work that makes LLM apps actually production-ready: prompt engineering, evaluation pipelines, observability (tokens/sec, cost-per-request), and trust & safety controls (PII handling, prompt-injection defenses, audit logging).

## 🚀 Featured Projects

**[CuePilot AI](https://github.com/vedant-abrol/CuePilot-AI-live-meeting-copilot)** — Real-time LLM meeting copilot built in Next.js 14 + TypeScript on Edge runtime. Streams mic audio through Whisper Large V3, surfaces grounded suggestions via gpt-oss-120B, and serves SSE responses with sub-500ms first-token latency. Hybrid prompting + Zod schema validation + dedupe-with-retry for production-quality output.

**AskMyDocs** — Multi-provider RAG service in Python (FastAPI + LangChain + Llama Index) over Gemini and GPT-4. Local Chroma vector store with sentence-transformer embeddings and a PyTorch cross-encoder for re-ranking. Fully containerized, on-device for data privacy.

**[TabWeave](https://github.com/vedant-abrol/TabWeave_AI-Powered-Chrome-Extension)** — AI-powered Chrome extension (React + TypeScript + GPT-4) that auto-organizes browser tabs through hybrid prompting, with a local sentence-transformer fallback for offline matching.

**[Personalized Event Recommendation Engine](https://github.com/vedant-abrol/Personalized-Event-Recommendation-Engine)** — Full-stack engine on TicketMaster API + MongoDB + Java Servlets (Jakarta EE), with the ELK Stack for real-time observability.
